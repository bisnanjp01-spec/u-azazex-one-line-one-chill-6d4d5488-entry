frighten a reader in one breath. A routine X-ray finds a small hand
gripping the patient's spine — and it has been holding on since birth.

## Run it

```sh
node main.ts
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). It is deterministic: the same line on
every run, no network, no randomness, no input files.
